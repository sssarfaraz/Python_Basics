# Python Basics Course 🐍

A comprehensive beginner-friendly course to learn Python fundamentals, starting with the essential `print()` function.

## 📚 Course Overview

This course is designed to help absolute beginners understand and master Python basics. It progresses from the simplest concepts to slightly more advanced topics, with plenty of practical exercises.

### Course Topics

1. **Introduction to Python** - Why learn Python?
2. **Chapter 1: The print() Function** - The fundamental way to display output
3. **Chapter 2: Variables and Data Types** - Storing and manipulating data
4. **Chapter 3: Basic Operations** - Arithmetic and string operations

## 🎯 How to Use This Course

### For Learners

1. **Read the Theory**: Start with `01_Python_Basics_Guide.md` to understand each concept
2. **Study Examples**: Review the code examples provided in the guide
3. **Practice**: Complete the exercises in `01_print_practice.py`
4. **Experiment**: Modify the examples and try your own variations

### Running the Exercises

#### Option 1: Run All Exercises at Once

```bash
python 01_print_practice.py
```

This will execute all 33 exercises and display their output in organized sections.

#### Option 2: Run Individual Exercises

Open `01_print_practice.py` in your Python IDE and call specific functions:

```python
from 01_print_practice import exercise_1_1_hello_world

exercise_1_1_hello_world()
```

#### Option 3: Interactive Learning

Copy exercises into your Python interpreter and modify them:

```python
# Try this in Python:
print("Hello", "World", sep="-")
# Modify sep to: " | ", " -> ", etc.
```

## 🚀 Getting Started

### Prerequisites

- Python 3.6 or higher installed on your system
- A text editor or IDE (VS Code, PyCharm, Thonny, etc.)
- Basic familiarity with your terminal/command prompt

### Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/python-basics-course.git
cd python-basics-course
```

2. Run the practice exercises:
```bash
python 01_print_practice.py
```

## 📝 Exercise Difficulty Guide
